# Workspace Agent Rules

## Design & Frontend Standards
- **Mandatory `design-taste-frontend` (`taste-skill`) Enforcement**: For all frontend development, landing pages, portfolios, UI components, and redesign tasks in this workspace:
  1. Follow the **Brief Inference** methodology.
  2. Declare a **Design Read** before generating frontend code.
  3. Enforce **Anti-Default Discipline** (avoid templated AI UI aesthetics).
  4. Refer to `design-taste-frontend` (`taste-skill`) guidelines in `.agents/skills/taste-skill/SKILL.md`.

- **Mandatory `impeccable` Design & Craft Skill Enforcement**: For all UI creation, component design, visual auditing, and frontend refinement in this workspace:
  1. Follow **Design Director Craft Standards** (production-ready code, zero shortcuts).
  2. Consult Impeccable playbooks, craft floor rules, and anti-pattern guidelines (`.agents/skills/impeccable/SKILL.md`).
  3. Perform structured bounded visual verification passes (desktop + mobile).

- **Mandatory Official GSAP Animation Suite Enforcement**: For all web animations, transitions, and scroll effects in this workspace:
  1. Enforce GSAP as the primary animation engine.
  2. Use `useGSAP()` hook for React component animations.
  3. Utilize `ScrollTrigger` for scroll-linked animations and pinning.
  4. Refer to GSAP skills in `.agents/skills/` (`gsap-core`, `gsap-react`, `gsap-scrolltrigger`, `gsap-timeline`, `gsap-plugins`, `gsap-performance`, `gsap-utils`, `gsap-frameworks`).
