# Project Overview — VAXSA Forex Observatory

> **Proprietary Market Microstructure Terminal, Quantitative Currency Research Desk & Institutional Portfolio Portfolio of Dharam Veer Singh Kirar.**

---

## 1. Executive Summary

**VAXSA Forex Observatory** is a high-performance, dark-aesthetic web application that bridges institutional macroeconomic research, Smart Money Concepts (ICT/SMC), and algorithmic market visualizers with elite frontend design standards.

Built using **React 19**, **TypeScript**, **Three.js / React Three Fiber**, **GSAP ScrollTrigger**, and **Tailwind CSS**, the site delivers an editorial, museum-grade financial experience. Visitors can explore real-time simulated pair pricing, spatial 3D currency strength matrices, 24/5 world session radars with 3D world clocks, order flow liquidity maps, audited trading performance curves, and an institutional trade journal with complete trade post-mortems.

## 4. Core Features & Capabilities

### 🌐 Global Forex Universe & 3D Core
- **Live Pair Tickers**: Real-time simulated price feeds, pip spreads, 24h delta percentages, and candlestick sparklines across Majors (`EUR/USD`, `GBP/USD`, `USD/JPY`), Crosses (`EUR/JPY`, `GBP/JPY`), and Metals (`XAU/USD`).
- **Interactive Pair Filtering**: Dynamic categorization across Majors, Crosses, and Precious Metals.
- **3D Interactive Core**: A rotating WebGL sphere with celestial orbital rings representing inter-dealer liquidity flow.

### ⚡ 3D Currency Strength Matrix
- Spatial 3D representation measuring relative strength/weakness across 8 global reserve currencies (`USD`, `EUR`, `GBP`, `JPY`, `AUD`, `CAD`, `CHF`, `NZD`).
- Algorithmic divergence calculation identifying high-probability pair combinations (e.g. Long Strongest vs. Short Weakest).

### ⏱️ 24/5 Forex Session Radar & 3D World Clock
- Real-time active trading session tracking: **Sydney**, **Tokyo**, **London**, and **New York**.
- Dynamic overlap indicators highlighting peak volatility windows (e.g., London / New York overlap accounting for over 52% of daily volume).
- 3D World Clock displaying geographic session arcs and UTC time synchronization.

### 🌊 Liquidity Topography & 3D Reactive Flow Field
- Interactive particle flow field canvas with real-time mouse repulsion simulating liquidity disturbance.
- Buy-Side Liquidity (BSL) and Sell-Side Liquidity (SSL) pool detection markers.
- Spatial visualization of Fair Value Gaps (FVG) and institutional order blocks.

### 📉 Verified Portfolio Analytics & Interactive Equity Curve
- Verified capital metrics:

### 📓 Institutional Trade Journal & Full-Screen Modal Inspector
- Granular historical trade logs featuring entry/stop/target prices, lot size, risk-to-reward ratios (`1:3.4` average), and PnL.

## 5. Design Philosophy & Visual Language

- **Obsidian Dark Luxury**: Grounded in deep charcoal/black tones (`#050505` to `#161616`), allowing vibrant market accents to gleam without visual fatigue.
- **Dynamic Spectral Aura**: Ambient background canvas that smoothly evolves its chromatic gradient (Cosmic, Opal, Navy, Violet, Burgundy) to harmonize with the specific section currently visible on screen.
- **Frosted Liquid Glassmorphism**: Tailored `.card-specimen-glass` components featuring sub-surface specular reflections, 28px backdrop blurs, and crisp 1px borders.
- **Editorial Typography Scale**: Bold display headlines via **Outfit**, razor-sharp editorial serifs via **Cinzel**, clean readable text via **Inter**, and monospace tabular digits via **JetBrains Mono**.
- **Tactile Reticle Cursor**: A custom dual-ring hardware cursor that snaps, scales, and pulses over interactive financial elements.
